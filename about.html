About the Project

This website is a student Full Stack Development project created to present information about selected aircraft and aerospace platforms. It demonstrates foundational web development concepts, including semantic HTML structure, CSS styling, and responsive layout techniques.

Project Objectives

  • Present information about selected aircraft.
  • Create a structured and user-friendly website.
  • Practice HTML5 and CSS3.
  • Learn JavaScript and DOM concepts in later stages.
  • Learn user authentication and database integration in later stages.

Technologies Used

This project follows a phased roadmap distinguishing current frontend implementations from planned backend technologies.

HTML5

Current Stage

Used to create the structure and content of the website.

CSS3

Current Stage

Used to style the website, including colors, spacing, borders and layout.

JavaScript

Current Stage

Used to add interaction, dynamic behavior, and form validation.

Supabase

Current Stage

Used for user authentication, database storage, and row-level security.

Website Structure

The website is organized into five core pages, each dedicated to a specific role in the user experience.

  • Home

    Introduction to the project.

  • Aircraft

    Displays the aircraft collection.

  • About

    Provides information about the project.

  • Contact

    Will provide a way for users to contact the project.

  • Sign In

    Will provide user authentication.

Aircraft Collection

The website contains selected aircraft from different categories, showcasing a diverse range of aerospace roles from combat air superiority to strategic humanitarian transport.

  • Fighter Aircraft
  • Stealth / Special Aircraft
  • Transport Aircraft
  • Helicopter
  • Special Mission / Presidential Transport

Learning Goals

This project is intended to help demonstrate the progression from frontend development toward full-stack development.

  1. Build the webpage structure using HTML.
  2. Style the website using CSS.
  3. Add interaction using JavaScript.
  4. Implement user authentication.
  5. Store user information using a database.
